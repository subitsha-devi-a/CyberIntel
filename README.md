# CyberIntel

**AI-Powered Cyber Threat Intelligence and Attack Relationship Discovery Using Hybrid GraphRAG and CAG**

CyberIntel is an AI-powered cybersecurity platform that analyzes uploaded threat intelligence documents, discovers relationships between cyber threats, and generates AI-based threat insights and defensive recommendations.

### Key Features
- PDF-based threat intelligence extraction
- Hybrid keyword and vector retrieval
- Knowledge graph relationship discovery
- AI-powered threat analysis
- Context-Augmented Generation (CAG) memory
- Interactive threat visualization

### Tech Stack
Python | Streamlit | NetworkX | PyVis | SQLite | Sentence Transformers | Scikit-learn | Nexus API

### Future Enhancements
- Live threat intelligence feeds
- Automated relationship extraction
- Advanced AI-based threat analysis
